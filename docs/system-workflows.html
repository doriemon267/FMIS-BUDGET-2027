01

User Roles & Permissions Overview

Each user is assigned one or more roles. Roles determine what pages are accessible, what actions can be performed, and what data is visible (which regions/offices/sections).

BUDGET PREPARER

Encodes PS, MOOE, Capital Outlay data. Creates and submits budget proposals for their assigned office/section.

BUDGET REVIEWER

Reviews submitted proposals from preparers. Can approve, return for revision, or forward to Budget Approver.

BUDGET APPROVER

Approves proposals reviewed by the reviewer. Can finalize or return to reviewer.

BUDGET OFFICER

Verifies and edits proposals before forwarding to Budget Manager. Can make edits with audit trail.

BUDGET MANAGER

Final authority in the budget chain. Finalizes proposals. Has access to all regions.

BUDGET PLANNING ANALYST

Reviews consolidated data, generates reports, handles BRD (Budget Review Document) analysis.

OVERALL BUDGET APPROVER

Top-level approver across all regions. Can see all proposals system-wide.

BUDGET ADMIN / SUPER ADMIN

Full system access. Manages users, roles, settings, fiscal years, and views all data. ID must be whitelisted in .env.

Authentication Flow

FMIS uses NIA Single Sign-On (SSO). Users log in once via the NIA Account Portal. The budget system receives an access token and issues its own httpOnly JWT cookie.

Budget Manager — Finalization Process

The Budget Manager has the final decision. Finalizing a proposal locks it — no further changes can be made. Managers can also view consolidated reports across all regions.

Security Events & Audit Trail

All significant user actions are logged to an immutable audit trail. Security events include failed logins, role violations, and all state-changing operations.
