# Server assets

Place **logo.png** (or **logo.jpg**) here to show your agency logo in the **Budget Summary Report** PDF header.

- Format: PNG or JPEG (SVG is not supported by the PDF library).
- Recommended size: at least 88×88 px (will be drawn at 44×44 pt in the PDF).
- If no logo file is present, the report still generates with the title only.
