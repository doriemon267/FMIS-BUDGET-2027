# Backup Scripts

This directory contains scripts related to the backup system.

## Scripts

- `initBackupSystem.js` - Initializes and configures the backup system

## Usage
```bash
# Run from SERVER root directory
node backup-scripts/initBackupSystem.js
```

## Notes
- These scripts handle backup system initialization and configuration
- Ensure proper permissions and disk space before running
- Review backup paths and settings before execution
